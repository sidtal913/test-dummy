# Hello App

A self-hosted .NET 8 web application with a Next.js React frontend, PostgreSQL database, and Progressive Web App (PWA) support.

## Stack

| Layer      | Technology                          |
|------------|-------------------------------------|
| Frontend   | Next.js 15 + React 19 (App Router)  |
| Backend    | ASP.NET Core 8 (Web API)            |
| Database   | PostgreSQL 16                       |
| PWA        | Web manifest + installable icons    |

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Node.js 18+](https://nodejs.org/) and npm
- [Docker](https://www.docker.com/) (recommended for PostgreSQL) **or** a local PostgreSQL 16 instance

## Quick Start

### 1. Start PostgreSQL

**Option A — Docker (recommended)**

```bash
docker compose up -d
```

**Option B — Local PostgreSQL**

Create a database and user matching the connection string in `src/HelloApp.Web/appsettings.json`.

### 2. Start the .NET API

```bash
cd src/HelloApp.Web
dotnet run
```

API runs at `http://localhost:5000`.

### 3. Start the Next.js frontend

From the project root:

```bash
npm install
npm run dev
```

Open **http://localhost:3000** — the hello page at `/` proxies API calls to the .NET backend.

### Production

```bash
npm run build
npm start

# In another terminal
cd src/HelloApp.Web && dotnet run
```

Or publish the full stack:

```bash
dotnet publish src/HelloApp.Web -c Release -o publish
```

## Configuration

Connection string in `src/HelloApp.Web/appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=helloapp;Username=helloapp;Password=helloapp_dev"
  }
}
```

Override in `appsettings.Development.json` or via environment variable:

```bash
export ConnectionStrings__DefaultConnection="Host=...;Port=5432;Database=...;Username=...;Password=..."
```

## Database Migrations

Migrations run automatically on startup. To create a new migration manually:

```bash
cd src/HelloApp.Web
dotnet ef migrations add <MigrationName>
dotnet ef database update
```

## PWA

The frontend is a Progressive Web App:

- **Manifest**: `manifest.webmanifest` (generated at build time)
- **Service worker**: auto-generated by `vite-plugin-pwa`
- **Installable**: supported on HTTPS or localhost

After building, verify PWA assets in `ClientApp/dist/`.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Database connection failed | Ensure PostgreSQL is running (`docker compose ps`) |
| Port 5432 in use | Stop other PostgreSQL instances or change the port in `docker-compose.yml` and connection string |
| Frontend not loading in dev | Ensure Node.js is installed; `dotnet run` launches Vite automatically |
| PWA not updating | Hard refresh or clear service worker cache in DevTools |
